Penjelasan tentang data yang disimpan di perangkat, layanan pihak ketiga, dan pilihan privasi saat menggunakan aplikasi Dompet Emas.

Terakhir diperbarui: 4 November 2026

Ringkasnya: Catatan emas, transaksi, dan foto yang kamu tambahkan disimpan di perangkat. Data portofolio tidak diunggah ke server Dompet Emas. Data yang disimpan di perangkat

Dompet Emas menyimpan data koleksi emas dan transaksi yang kamu masukkan, termasuk merek atau toko, jenis emas, berat, kadar, tanggal, harga beli atau jual, biaya tambahan, catatan, serta foto perhiasan yang kamu pilih atau ambil. Harga manual dan pengaturan aplikasi juga disimpan secara lokal.

Aplikasi tidak memerlukan akun. Data koleksi, transaksi, catatan, dan foto tidak dikirim ke server Dompet Emas atau pengiklan.

Koneksi internet dan harga emas

Aplikasi menghubungi server Dompet Emas melalui HTTPS untuk mengambil katalog dan harga emas yang tersedia. Permintaan harga tidak memuat data koleksi atau transaksi pribadi. Seperti layanan internet pada umumnya, server dapat menerima informasi teknis koneksi seperti alamat IP dan header permintaan. Harga terakhir yang tersimpan dapat dilihat saat offline.

Layanan pihak ketiga

  • Google AdMob (iklan): Pada versi yang menampilkan iklan, Google dapat memproses pengenal perangkat atau iklan, alamat IP, informasi perangkat, dan interaksi dengan iklan untuk menayangkan, mengukur, serta melindungi layanan iklan. Data portofolio tidak diberikan kepada AdMob. Lihat Kebijakan Privasi Google.
  • Firebase Cloud Messaging (notifikasi harga): Jika kamu mengaktifkan notifikasi harga, aplikasi berlangganan topik notifikasi. Firebase mengelola token perangkat untuk pengiriman notifikasi. Token tidak dikirim ke server Dompet Emas; isi notifikasi tidak memuat data koleksi atau transaksi. Notifikasi dapat dimatikan di Pengaturan. Lihat Privasi Firebase.
  • Firebase Crashlytics (diagnostik): Pada build rilis, laporan saat aplikasi mengalami crash dapat dikirim ke Firebase, termasuk informasi perangkat, versi aplikasi, dan detail teknis crash. Laporan ini dipakai untuk memperbaiki aplikasi; aplikasi tidak menambahkan data portofolio ke laporan. Aplikasi tidak memakai Firebase Analytics untuk mencatat event penggunaan. Lihat Privasi Firebase.

Penanganan dan masa simpan data oleh Google mengikuti kebijakan layanannya. Pengaturan privasi iklan pada perangkat atau akun Google dapat memengaruhi personalisasi iklan.

Izin dan akses perangkat

Aplikasi menggunakan akses internet dan status jaringan untuk mengambil harga serta menjalankan layanan di atas. Izin notifikasi diminta ketika kamu mengaktifkan notifikasi harga pada perangkat yang memerlukannya. Jika kunci biometrik diaktifkan, autentikasi dilakukan melalui sistem perangkat; aplikasi tidak menerima atau menyimpan sidik jari atau data wajah.

Foto perhiasan dipilih melalui pemilih foto sistem atau diambil menggunakan aplikasi kamera. Dompet Emas tidak meminta akses menyeluruh ke galeri, kontak, atau lokasi perangkat.

Keamanan dan backup

Data aplikasi disimpan di ruang penyimpanan lokal aplikasi pada perangkat. Backup dibuat hanya saat kamu memilihnya, dienkripsi dengan passphrase yang kamu tentukan, lalu disimpan ke lokasi yang kamu pilih melalui pemilih file sistem. Simpan passphrase dan file backup dengan aman. Dompet Emas tidak mengunggah file backup ke servernya.

Jika kamu menyimpan atau membagikan file backup melalui layanan lain, pengelolaan salinan tersebut mengikuti kebijakan layanan yang kamu pilih.

Penyimpanan dan penghapusan data

Data yang kamu masukkan tetap tersimpan di perangkat sampai kamu menghapusnya atau menghapus data aplikasi. Untuk menghapus data buatan pengguna, buka Pengaturan → Data → Hapus data saya. Tindakan ini menghapus koleksi, transaksi, merek kustom, harga manual, dan foto terkait dari perangkat; katalog merek bawaan tetap tersedia.

File backup yang telah kamu simpan di luar aplikasi perlu dihapus secara terpisah dari lokasi penyimpanannya. Data teknis yang telah diproses layanan Google mengikuti kebijakan penyimpanan dan penghapusan masing-masing layanan.

Perubahan kebijakan

Kebijakan ini dapat diperbarui saat fitur atau cara pemrosesan data berubah. Tanggal pembaruan terbaru akan ditampilkan di bagian atas halaman ini.
